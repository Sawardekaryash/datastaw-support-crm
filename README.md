\# Datastaw Support CRM



A Customer Support Ticket Management System built as part of the Datastaw AI Tech Intern Assessment.



The application allows support teams to create, manage, search, filter, and update customer support tickets with internal notes.



\## Features



\- Create new support tickets

\- Automatically generate ticket IDs

\- View all support tickets

\- Search tickets by:

&#x20; - Ticket ID

&#x20; - Customer name

&#x20; - Customer email

&#x20; - Description

\- Filter tickets by status

\- View complete ticket details

\- Update ticket status

\- Add internal support notes

\- Dashboard with ticket statistics

\- REST API using FastAPI

\- SQLite database

\- Responsive web interface

\- Swagger API documentation
